    Rekordbox

    Writes key, BPM, beatgrid and hot cues into a rekordbox.xml that Rekordbox reads as a library.

    The browser does not know the full path. Enter the folder that contains the folder you added. Rekordbox finds the tracks via this path.
    1. Unzip the saved ZIP. It contains rekordbox.xml.
    2. Rekordbox: Preferences → Advanced → Database → rekordbox xml, choose the file under "Imported Library".
    3. Preferences → View → Layout: enable "rekordbox xml" in the sidebar.
    4. In the sidebar under rekordbox xml, select the tracks, right-click → Import To Collection.
